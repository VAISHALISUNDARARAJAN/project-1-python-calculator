# Python Calculator

A simple menu-based calculator developed using Python as part of the Cognorise Infotech Python Development Internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Square calculation
- Square root calculation
- Handles division by zero
- Handles invalid input
- Simple menu-based interface
- Reusable Python functions

## Technologies Used

- Python
- Python math module

## How to Run

1. Make sure Python is installed on your computer.
2. Open `calculator.py` using Python IDLE or any Python IDE.
3. Run the program.
4. Select an operation from the menu.
5. Enter the required numbers.
6. The calculator displays the result.

## Available Operations

| Option | Operation |
|---|---|
| 1 | Addition |
| 2 | Subtraction |
| 3 | Multiplication |
| 4 | Division |
| 5 | Percentage |
| 6 | Square |
| 7 | Square Root |
| 8 | Exit |

## Error Handling

The application handles:

- Invalid non-numeric input
- Division by zero
- Square root of a negative number
- Invalid menu choices
